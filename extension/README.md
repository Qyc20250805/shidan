# 拾单 · 四商家加购助手 0.4.0

## 安装

1. 下载拾单的 shidan-helper.zip，解压。第一层就是 manifest.json。
2. 电脑 Chrome 打开 chrome://extensions，开启开发者模式，点击“加载已解压的扩展程序”，选择上述文件夹。旧版先移除，避免两个助手同时运行。
3. 刷新拾单及商家页面。顶部填写商家网址，勾选数量合计不超过 20 件，点击“开始加购”。首次建议仅选 1 件。

支持 www.petit-bateau.co.jp、www.panpantutu.com、www.mikihouse.co.jp、www.montbell.com/jp/en/products。
手机可以录入、查看同步结果；加购需在安装扩展的电脑 Chrome 中运行。购物车是该浏览器中的商家购物车，不随拾单同步码同步到其他浏览器。

## 处理规则

- 优先在新标签页打开明细保存的商品链接；商品详情页链接为必填，不再以首页或搜索替代缺失链接。纯图片文件、商家首页不能代替商品页。购物车基线在另一个后台标签页读取，完成后自动关闭。
- Petit Bateau：所选尺码后的完整商品番号必须与订单货号一致。例如 A0DV401090 对应 95cm；截断编号或不同尺码编号不会猜测。
- panpantutu / Miki House：严格匹配商品型号（网址 products 后的编号）或完整 variant SKU；按网站尺码字段选规格。不按前缀模糊匹配，不猜测尺码换算。
- Montbell 日本英文站：精确匹配货号、尺码、颜色和现有发货区域。多个颜色需用户选定；发货区域/加购入口不唯一则停止。助手不修改配送国家或地址。
- 系统从商品页自动读取网页主图并回写拾单，客户无需上传图片。历史参考图片仍保留在拾单明细中。用户核对货号、目标尺码、网页主图与所需款式一致，勾选确认后读取并回写当前规格的网页原价、售价、币种和读取时间，再手动确认加入 1 件。没有自动图片识别模型。
- 每次只加 1 件，核验指定规格购物车恰好增加 1，其他规格不变后才计为成功。数量 2 需两次确认。全部处理后停在购物车。
- 主图无法读取、货号/链接/尺码冲突、缺货、搜索不唯一、图片不符、页面变化、网络结果不明：需人工核对。商家明确拒绝加购（HTTP 4xx）：加购失败。不自动重试。
- 拾单下单表显示待人工核对 / 已处理 / 需人工核对 / 加购失败及原因；所有明细始终可以重新勾选、取消及手动再发起新批次。重新发起不会自动重复点击，仍需逐件人工确认。

## 中断和边界

加购前持久保存检查点，刷新或重启不会重复点击。停止扩展或关闭商家标签不会撤销已加入商品。再次处理前先检查购物车；可以返回拾单选择下一条并发起下一批，商品页立即打开，加购按批次顺序执行。不要同时手工改购物车或在两台电脑运行同一批次。连续 10 分钟未响应的会话会标记需核对，不再卡住；新批次仍需人工核对。

仅加购物车，不填地址、不提交订单、不支付、不登录商家。不访问 Supabase，不读取同步码、客户昵称或账单金额。批次图片保存在本机扩展中，不上传给商家。权限仅限拾单和四家商店，Manifest V3，无远程执行代码，无 npm 构建依赖。

网站结构和库存会变化；无法确认时安全停止。限当前站点常规商品，定制、订阅、多件起购、额外规格/配送条件不自动处理。

## 固定接龙与计价更新（2026-09-29，v0.4.0 更新包）

在拾单点击“粘贴接龙”，粘贴下列格式后点击“一键导入”。可用空行分组，数量省略默认为 1。缺少昵称、货号、尺码或有效商品链接的明细会保存为信息不完整，补齐后才能加购。

```
昵称：小林
货号：A0DV401090
尺码：95
商品链接：https://www.petit-bateau.co.jp/products/a0dv4-bebe-25h81-cardigans
数量：1
```

网页主图、原价、当前售价和币种只读。原价不参与计算；应收人民币 = 当前售价 × 核算折扣 × 数量 × 汇率 + 行运费。默认跟随拾单顶部设置；“高级计价”可明确选择单条覆盖。旧明细的已有覆盖值保留。默认运费为 0 元。

更新本次安装包后请覆盖原扩展目录并在 chrome://extensions 重新加载，再刷新拾单和商家页。本次保留版本号 0.4.0，通过 fixed-chain-v1 能力标识区分旧包；旧包会提示更新。

新增验证：17 项扩展测试、固定接龙/只读字段/计价继承与覆盖/回写/异常保存回归，以及选单/删除/同步回归通过。真实 Petit Bateau 商品页选择 95 cm 后读取 A0DV401090、原价 11000、售价 8800 JPY 和主图；未在本次验证中加入购物车或结账。Shopify 的当前币种及价格来源遵循官方 Ajax Product API：https://shopify.dev/docs/api/ajax/reference/product 。
