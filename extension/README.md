# 拾单 Chrome 待加购清单（最小版本）

1. 下载仓库，打开 Chrome 的 `chrome://extensions`，启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本目录 `extension/`。
3. 刷新 https://qyc20250805.github.io/shidan/ ，在下单表勾选商品，点击扩展图标。

扩展显示货号、尺码、商品链接和数量。分页后保留已观察到的勾选条目；若安装前已有跨页选择，需刷新后重新勾选。读取不完整时会提示，绝不悄悄漏项。清单只存当前页面内存，刷新页面或取消勾选会清空。缺失字段直接标明，链接由用户主动打开。

仅使用该网站的内容脚本和扩展内部消息，不读取登录凭据，不联网传输清单，不自动加购、下单或支付。没有后台服务、外部消息入口或额外权限。
